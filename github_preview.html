A cosmic-violet split-flap departure board with CRT phosphor warping

✨ Features

  • 🎰 Mechanical split-flap flip — faithful 3D card-flip animation per tile
  • 📺 CRT phosphor warp — Three.js WebGL scanlines, bloom, RGB shift, mouse parallax
  • 🪗 Accordion transition — tiles stretch out / squeeze in with spring physics
  • 🎨 Cosmic Violet palette — #c755f7 plasma on #0d1117 GitHub dark
  • ♿ Accessible — prefers-reduced-motion respected, proper ARIA labels
  • ⚡ Zero build step — pure ES modules with importmap, no bundler needed

🚀 Usage

<!-- 1. Include the CSS -->
<link rel="stylesheet" href="SplitFlapText.css" />

<!-- 2. Import via ES module -->
<script type="importmap">
  { "imports": { "react": "https://esm.sh/react@19", ... } }
</script>

<script type="module">
  import SplitFlapText from './SplitFlapText.js';

  createRoot(document.getElementById('root')).render(
    React.createElement(SplitFlapText, {
      words: ['think2thrive', 'explore'],
      flipDuration: 0.11,
      cycleDelay: 2400,
      tileColor: '#161b22',
      textColor: '#ffffff',
      padTo: 12
    })
  );
</script>

PropTypeDefaultDescription
